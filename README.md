# Loan Cost Explainer

Enter a loan's amount, rate and term. See what it really costs in plain
language, and what paying a little extra each month does.

Portfolio project by Steven Babb. Built in code first, then documented in Figma.

## Run it

```
npm install
npm run dev
```

Then open http://localhost:3001.

## Status

The whole flow works: one question, the loan's numbers, and the explanation.
`npm run verify` checks the loan math, the input checking and the color
contrast. The design decisions are logged in [docs/DECISIONS.md](docs/DECISIONS.md).
